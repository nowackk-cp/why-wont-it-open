# Fuzzing the PE parser

`fuzz_pe` is a libFuzzer target (MSVC `/fsanitize=fuzzer /fsanitize=address`) that feeds arbitrary
bytes to `neden::pe::parse`. `core/src/pe/pe.cpp` is compiled directly into the fuzz target so it is
instrumented without touching the shipping library.

Tested with Visual Studio 2022 (17.14) in an **x86 (`-A Win32`)** build; x64 should work the same.

```bash
cmake -S . -B build/fuzz -A Win32 -DNEDEN_FUZZ=ON -DBUILD_TESTING=OFF
cmake --build build/fuzz --config Release
build/fuzz/fuzz/Release/fuzz_pe.exe -max_total_time=30 -max_len=8192 build/fuzz/work fuzz/corpus
```

Notes:

- The ASan runtime DLL (`clang_rt.asan_dynamic-i386.dll`) is copied next to `fuzz_pe.exe` after the build; it lives in
  `<VS>\VC\Tools\MSVC\<ver>\bin\Hostx86\x86`. Run from a "Developer Command Prompt" or add it manually.
- `fuzz/corpus/` holds three small seeds generated by `gen_seeds.exe fuzz/corpus` (built from
  `tests/pe_builder.h`). The first argument directory (`build/fuzz/work`) receives new findings.
- Real system binaries make good extra seeds; pass a larger `-max_len` for them.
